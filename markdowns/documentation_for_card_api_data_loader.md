## Magic: The Gathering Card Loader

---

This block fetches card data from the Magic: The Gathering API and loads it into a Pandas DataFrame.
The data includes card details like names, sets, types, and other attributes from the official MTG database.

The code makes use of the public MTG API endpoint at `api.magicthegathering.io/v1/cards` and handles the 
response data with proper error checking and UTF-8 encoding cleanup.

Press the "Play" icon button in the top right corner to execute this block and fetch live MTG card data.
